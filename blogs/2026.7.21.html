电动力学第一章：麦克斯韦方程组

第一章不是简单罗列四个方程，而是从静电、静磁和电磁感应的实验规律出发，说明麦克斯韦方程组如何建立，并继续讨论介质和边界条件怎样进入这套理论。

学习材料：周磊《电动力学》讲义，第一章。

1. 静电与静磁的两幅图像

库仑定律与叠加原理把电荷之间的作用改写为空间中的电场。用散度和旋度描述后，静电场是“有源、无旋”的；稳恒电流产生的静磁场则是“无源、有旋”的。

∇ · E = ρ / ε₀，  ∇ × E = 0
∇ · B = 0，  ∇ × B = μ₀j（稳恒电流）
E = −∇φ，  B = ∇ × A

这一对比让我更清楚地看到：散度回答场线从哪里产生或汇聚，旋度回答场是否在局部环绕。电偶极子与磁偶极子的远场形式相似，也提示了电、磁之间更深的结构对称性。

2. 从电磁感应到完整方程组

法拉第定律表明，变化的磁场会激发有旋电场，而且这种电场不依赖线圈是否存在；线圈只是探测它的工具。反过来，原来的安培环路定理只适用于稳恒电流，因为一般情况下必须满足连续性方程 ∇ · j + ∂ρ/∂t = 0。

麦克斯韦引入位移电流 ε₀∂E/∂t，使安培环路定理与电荷守恒相容。真空中的四条方程因此成为：

∇ · E = ρ / ε₀
∇ × E = −∂B / ∂t
∇ · B = 0
∇ × B = μ₀j + μ₀ε₀∂E / ∂t

位移电流不只是为了修补公式。它说明变化的电场本身能够激发磁场，与“变化的磁场激发电场”构成闭环，也为电磁波能够脱离源而传播埋下了基础。

3. 介质：把微观响应整理成宏观量

介质放入场中后会极化或磁化，产生束缚电荷与束缚电流。第一章给出的关键关系是：

ρP = −∇ · P
jP = ∂P / ∂t，  jM = ∇ × M
D = ε₀E + P，  H = B / μ₀ − M

D 与 H 的引入把方程中的源整理为自由电荷和自由电流；它们是便于处理介质的辅助量，真正对电荷产生力的仍是 E 与 B。麦克斯韦方程给出普遍结构，材料差异则进入本构关系，例如线性介质中的 D = εE、B = μH，以及导体中的 j = σE。

4. 边界条件来自积分形式

界面上微分形式可能失去意义，但积分形式仍然成立。用跨越界面的薄柱和小回路，可以直接得到：

n · (D₁ − D₂) = σf
n · (B₁ − B₂) = 0
n × (H₁ − H₂) = αf
n × (E₁ − E₂) = 0

没有自由面电荷与自由面电流时，D、B 的法向分量连续，E、H 的切向分量连续。这样理解比单独背四条边界条件更稳：散度方程控制法向分量，旋度方程控制切向分量。

5. 本章收获与下一步

  • 散度与旋度不是纯粹的计算工具，而是对矢量场局部结构的完整描述。
  • 电荷守恒是判断场方程是否自洽的重要约束，位移电流正是从这一约束中自然出现。
  • 场是独立的物理存在，不只是电荷之间“超距作用”的记账方法。
  • 介质问题的复杂性主要进入本构关系，而不是改变麦克斯韦方程的基本结构。

下一步需要自己重推一遍积分形式与微分形式的转换，特别注意源坐标 r′、观察点坐标 r 以及 ∇、∇′ 的区别；同时用薄柱和小回路重新推导四条边界条件。完成这些之后，再从无源方程组推出电磁波方程。
